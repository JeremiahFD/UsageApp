# Security

## Reporting a vulnerability

Please report security issues through a
[private GitHub security advisory](https://github.com/JeremiahFD/UsageApp/security/advisories/new)
instead of opening a public issue.

Include the affected UsageApp version, Windows version, reproduction steps, and
any relevant logs after removing account details, tokens, paths, and other
personal information.
